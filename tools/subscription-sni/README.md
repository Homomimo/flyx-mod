# 订阅流量统计：按时段查看访问 SNI

面板管理端 → 订阅 → 点开一条分享订阅 → 流量统计。点选趋势图或「查看时段」可切换小时、日期、月份。SNI 统计独立于计费；不影响上下行字节。没有数据时不会用 DNS、代理目标或示例数据填充。演示站（`VITE_DEMO=true`）使用 `.test` 假域名。

## 自动采集（自建 Linux 节点）

没有面板开关。升级面板和 Agent 后，Agent 每 3 秒读取已启用内核的订阅标记，自动启动、更新或停止内置采集器。原有和新增的可归属订阅都适用；列表为空时不创建采集规则。无需手动运行 Python 或填写 ID。部署前请告知订阅使用者域名统计范围、用途和保留期限。

原生安装或更新脚本会在支持的发行版上尝试安装 Python 3、libnetfilter_log、sqlite3 和 nftables；仅替换二进制不会安装系统依赖。Docker 需更新 **Agent 镜像**；沿用原来的 Agent 数据卷和网络权限，不需要单独启动采集容器。原生库沿用 /var/lib/flyx-sni；Docker 使用 Agent 数据卷内的 sni 目录。旧版若单独运行过手动采集器，应先停止它以释放 NFLOG 组；旧 Docker 单独挂载的库不会自动迁移。

需要支持 NFLOG 和 @ih 的 nftables、可用的订阅出站标记及相应权限。采集失败不阻断转发，Agent 日志记录错误并自动重试。无标记、旧 Agent、离线或缺少权限时不能保证观察到握手。重启、订阅变更或故障恢复期间可能漏计。正常停机清理专用 nft 表；只回收带本采集器所有权标识的残留表。

## 数据边界

- 只观察自动识别出的订阅标记的出站 TCP/443 中可以在单个报文（最多 8192 字节）解析的 TLS ClientHello。分片、跨包、大握手、QUIC/UDP、未保留标记的中继及导入节点可能无结果；ECH 不能还原内层域名。握手不是访问成功的证明。
- 原始报文只经过内存；节点库只写入订阅 ID、分钟、域名、次数及采集器心跳。没有 IP、URL、路径、报文文件，不把浏览历史复制到面板数据库。按当前订阅所属的自建节点只读查询，离线/移出订阅的节点不会贡献历史结果；停止采集、但 Agent 在线时仍可查保留期内的记录。
- 默认只展示最近 30 天的样本，按月查看也不会延长保留期。采集器运行时清理超过 30 天的记录；停用后若要立即清除，先停止采集器，再由节点管理员清理专用数据目录。节点磁盘应受保护，避免跨面板或重置订阅 ID 后继续复用同一份库。
- 同一订阅、同一 ClientHello 随机值短时去重。整个节点每秒最多观察约 512 个样本，每订阅每分钟最多 256 个域名，数据量过大时可能少计。每节点最多返回 100 个域名；发生截断时面板提示不完整。数据库限制 131072 页（默认页大小时约 512 MiB，不含 WAL）；写满将停止而不是无限扩张。

## 自测

`python3 -B -m unittest discover -s tools/subscription-sni` 测试真实 TLS ClientHello 解析、不带 SNI、订阅隔离、跨分钟及重传去重。生产启用前还需在实际 Linux 节点验证网络命名空间、socket mark、nft 和 NFLOG 权限。
